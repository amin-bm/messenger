مشکل احتمالی در telegramBack (نسخه جدید)

در نسخه‌ی جدید `telegramBack()` فقط URL عوض می‌شود و با `updateMobileLayout()` سایدبار نمایش/مخفی می‌شود، ولی محتوا‌ی `#sidebar-content` ممکن است خالی/قدیمی بماند؛ چون این بخش معمولاً از طریق WebSocket (`online_status_handler`) آپدیت می‌شود و وقتی دیگر full reload نداریم، همیشه تضمین نیست که بلافاصله پیام WS برسد.

اصلاح دقیق در `templates/base.html`

1) در حالت موبایل، ترتیب را درست کن: اول `history.pushState('/', ...)` بعد `updateMobileLayout()` (تا layout بر اساس مسیر جدید محاسبه شود).
2) بعد از برگشت، یک رفرش سبک برای WS انجام بده: با `htmx.trigger(presence-ping-form, 'submit')` یک ping بزن تا سرور eventهای لازم را بفرستد. اگر `#sidebar-content` هنوز خالی بود، یک بار دیگر با تاخیر کوتاه تکرار کن.

کد پیشنهادی (همان چیزی که باید در base.html اعمال شود):

```js
function _refreshSidebar() {
  var presenceForm = document.getElementById('presence-ping-form');
  if (presenceForm && window.htmx && typeof window.htmx.trigger === 'function') {
    try { window.htmx.trigger(presenceForm, 'submit'); } catch (e) {}
  }

  var sidebarContent = document.getElementById('sidebar-content');
  if (sidebarContent && !sidebarContent.innerHTML.trim()) {
    window.setTimeout(function () {
      var sc = document.getElementById('sidebar-content');
      if (sc && !sc.innerHTML.trim()) {
        var pf = document.getElementById('presence-ping-form');
        if (pf && window.htmx && typeof window.htmx.trigger === 'function') {
          try { window.htmx.trigger(pf, 'submit'); } catch (e) {}
        }
      }
    }, 500);
  }
}

function telegramBack() {
  setTelegramNavDir('back');
  var isMobile = window.matchMedia('(max-width: 767px)').matches;

  if (isMobile) {
    if (document.documentElement.dataset.tgNavLock === '1') return;
    document.documentElement.dataset.tgNavLock = '1';
    document.documentElement.classList.add('tg-leave-back');

    window.setTimeout(function () {
      if (typeof window.RtChat !== 'undefined' && window.RtChat.cleanup) window.RtChat.cleanup();
      var content = document.getElementById('tg-chat-content');
      if (content) content.innerHTML = '';
      try { history.pushState({}, '', '/'); } catch (e) {}
      updateMobileLayout();
      highlightActiveChat();
      clearTelegramNavDir();
      _refreshSidebar();
    }, 140);
    return;
  }

  if (typeof window.RtChat !== 'undefined' && window.RtChat.cleanup) window.RtChat.cleanup();
  var content2 = document.getElementById('tg-chat-content');
  if (content2) content2.innerHTML = '';
  try { history.pushState({}, '', '/'); } catch (e2) {}
  highlightActiveChat();
  updateMobileLayout();
  _refreshSidebar();
}
```
